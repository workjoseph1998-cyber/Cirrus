# V21.2 UI review — Midnight Azure

The approved image in the conversation was inspected and used as the visual direction.
The release implements its navy left navigation, pale blue content backdrop, compact
top bar, clear page hierarchy, icon-backed KPI cards and dense quotation table.

## Intentional differences from the mockup

- The original Cirrus logo is retained; the mockup's alternate cloud logo was not substituted.
- Cards show real application/account values. Labels explain the scope: matching documents, my pending approvals, sent quotations and my saved favorites. No sample counts or unsupported growth percentages appear.
- Manage remains the authorized grouped management **panel**, rather than introducing a second row-action system. The existing Select button and Tools & management drawer remain available for comparison and other existing tools.
- Only existing destinations are shown in navigation; speculative “My quotations” or other new pages were not created.
- The existing theme selector is retained rather than replacing Light / Dark / System with a moon-only toggle.
- The exact existing quotation filter form remains intact. Styling, surrounding spacing and the summary strip were changed, without changing fields, structure, handlers or saved selections.
- The dark theme uses restrained navy header shading instead of a bright illustration to preserve comfortable contrast.
- The quotation editor, including its older footer, is deliberately excluded from the new shell.

All screenshots below use synthetic data. Before captures run the untouched V21.1
commit; after captures run V21.2 with the same synthetic scenario at 1366×768.
These are full-page captures, so the image height can exceed the viewport.
