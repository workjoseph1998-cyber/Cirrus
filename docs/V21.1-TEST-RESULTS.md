# V21.1 verification and known limitations

All checks use temporary synthetic data in the cloud Linux environment. No production profiles, documents, email accounts or servers were used.

## Executed checks

Final combined regression run: **316 tests passed in 218.995 seconds**, including all six new UX tests. No test failures remain. The suite emits pre-existing ResourceWarnings about synthetic file handles.

- Original automated suite: **310 tests passed**, 210.844 seconds. Coverage includes quotation calculations, exports, revisions, approvals/reminders, document storage/deletion, customers, reports, role permissions, backups, isolation and simulated Windows installer flows.
- New UX tests: **6 passed**. They check movement of secondary tools, no duplicate notes/check links, editor asset exclusion, viewer restrictions, favorite add/remove state, permission-filtered grouped search, unchanged quotation filters and hashes of protected source files.
- Focused V21 regression rerun: **18 tests passed** after the final Manage workflow changes.
- V21.1 Chromium browser suite: **12 scenario groups passed**, no JavaScript errors. Checks cover 30 quotation rows, density, optional columns/reset/persistence, bulk selection and cancelled archive confirmation, clipboard, Back preserving query/sort/page size, favorites, internal notes, unsaved changes, pre-send checks, grouped search/keyboard shortcuts, sidebar persistence and editor asset isolation. Light/dark screenshots at 1440×900, 1366×768, 1024×768 and 768×1024 show no page-level horizontal overflow.
- Existing V21 browser suite: passed after updating its Copy Link navigation to the requested Manage location; includes mobile, customer timeline, favorites, internal notes, pre-send and the existing editor.
- Independent baseline comparison: quotation editor preview content is **pixel-identical** to the extracted uploaded V21 in both light and dark modes at 1440×1000. The 16px Chromium native scrollbar gutter is excluded because its arrow hover/focus rendering varied between browser contexts. This compares the visible preview, not every possible editor state. Source hashes additionally protect editor layout/scripts/styles, formulas, export and approval code, the original quotation-list stylesheet, and Windows launchers.
- `git diff --check`: passed.

Compact rows measured **45px**, comfortable rows **55px**, with the test fixture. Long records may require horizontal scrolling on smaller screens. No unmeasured speed improvements are claimed. The listing's fixed vertical height was removed to avoid an extra vertical scroll region.

Machine-readable browser/editor measurements and focused test logs are in `docs/v21.1-measurements/`. Uploaded V21 measurement files elsewhere in `docs/` are historical and are not V21.1 test evidence.

## Known limitations and unexecuted checks

- Native Windows Server 2022 / IIS deployment, production data migration, real SMTP delivery, actual backup infrastructure and Windows PDF automation were **not executed**. Existing automated simulations passed; staging verification by the operator remains required.
- Not every old version-specific browser script was run. The full Python regression suite and the two V21 browser scripts provide the release checks.
- User browser preferences for columns, sorting and page size are scoped by account in localStorage; return location/scroll is scoped by account in sessionStorage. These preferences stay on that browser. Existing theme/sidebar account persistence remains server-backed.
- The existing global search remains a server-rendered search page; keyboard traversal improves its results without introducing another search system or predictive remote requests.
- Sticky table headers use the existing horizontal table container; browser overflow rules can limit viewport stickiness when horizontal scrolling is active.
- Destructive document operations retain their existing review pages, confirmations and backend cleanup rules. No storage cleanup redesign was attempted.
- The protected editor deliberately retains its original V21 footer and controls. Original V21 build/API metadata is retained for compatibility; the release commit identifies this V21.1 source distribution.
