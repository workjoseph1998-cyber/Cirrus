# V21.1 changed files

The baseline is the uploaded V21 package, tagged `v21-baseline`. All other baseline application files are retained in the complete source ZIP.

## Application

- `workspace_app/templates/base.html`: conditional UX assets, navigation groups, release footer and breadcrumbs. Both ordinary and Excel-import quotation editors are excluded.
- `workspace_app/templates/documents.html`: remove secondary V21 row tools only; preserve the exact original filter form.
- `workspace_app/templates/document_manage.html`: grouped actions, workflow/reminders, history and family management.
- `workspace_app/templates/customer_header.html`: preserve list state through customer Back link.
- `workspace_app/templates/edit.html`: explicit unsaved-change protection for record forms.
- `workspace_app/templates/v21_search.html`: grouped existing search results and empty state.
- `workspace_app/templates/v21_tools.html`: display saved favorite state/removal and avoid duplicate Manage tools.
- `workspace_app/v21.py`: supply account favorite IDs to templates using the existing table.
- `workspace_app/static/ux21.css`: isolated navigation, list, search, density and responsive refinements.
- `workspace_app/static/ux21.js`: column preferences, list state, keyboard navigation, feedback, validation and bulk confirmations.
- `workspace_app/static/v21.js`: extend existing unsaved detection to implicit text and number/email fields.

## Validation

- `tests/test_v21_1.py`: six synthetic UX, permissions and source/filter regression tests.
- `tests/v21_1_browser.py`: functional Chromium checks and screenshots.
- `tests/v21_1_editor_compare.py`: compare editor preview pixels to the uploaded baseline.
- `tests/v21_1_filters.html`, `tests/v21_1_protected.json`: original filter fixture and protected-file hashes.
- `tests/v21_browser.py`: update the old Copy Link check to navigate through Manage.
- `docs/v21.1-measurements/*`: current release test evidence.
