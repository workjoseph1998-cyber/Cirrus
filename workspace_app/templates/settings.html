Offline backup & restore instructions

Stop the server with Ctrl+C first. From the application directory:

.venv\Scripts\python scripts\backup.py backup C:\Backups\cirrus-workplace.zip
.venv\Scripts\python scripts\backup.py restore C:\Backups\cirrus-workplace.zip --target C:\CirrusRestored

Backups include SQLite, settings and attachments with integrity hashes. Restore only creates a new directory; it never overwrites existing data. Set CIRRUS_DATA_DIR to the restored directory, then restart.
