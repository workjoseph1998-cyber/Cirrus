How these amounts are calculated

Quoted value = full saved contract duration + one-time fees + saved tax treatment, using only the latest accessible revision per family. Monthly quoted fees = initial payable monthly fees excluding separately added contract tax and one-time charges (tax already included in prices stays included); promotional and regular fees are shown separately on each quotation. Won value = frozen accepted contracts, filtered by outcome date. Quotations use issue date. These are calculated quotation amounts, not payments received.
